# 房间签到管理系统 - 产品需求文档

## 1. 产品概述

一个完全离线的房间循环签到管理工具，通过浏览器IndexedDB实现本地数据持久化，无需任何网络连接或后端服务。所有房间独立遵循15天签到周期，主界面根据距下次签到天数显示直观的颜色状态，并提供丰富的批量操作和数据管理功能。

**目标用户**：需要对多个房间进行周期性巡检签到的管理人员，如物业管理员、酒店前台、设备维护人员等。

## 2. 核心功能

### 2.1 房间管理

| 功能 | 描述 |
|------|------|
| 新增房间 | 输入房间名称和当前签到人 |
| 删除房间 | 确认后删除，支持多选删除 |
| 修改房间 | 双击单元格直接编辑，或右键菜单修改 |
| 右键菜单 | 提供删除、修改签到人、查看历史等快捷操作 |
| CSV批量导入 | 解析CSV文件批量创建房间，支持格式：房间名,签到人 |

### 2.2 签到周期规则

- **周期计算**：下次签到日 = 上次签到日 + 15天
- **首次签到**：新建房间时默认签到状态，下次签到日为今天+15天
- **签到操作**：
  - 点击"确认签到"：记录今天为签到日，重置下次签到日为今天+15天
  - 点击"撤销签到"：清除本次签到记录，恢复到上一个周期

### 2.3 状态显示

主列表根据距下次签到天数显示不同颜色：

| 状态 | 条件 | 颜色 | 文字 |
|------|------|------|------|
| 已签到 | 距下次签到 ≥ 14天（刚签到） | 绿色 | 已签到 |
| 明天需签到 | 距下次签到 = 1天 | 橙色 | 明天需签到 |
| 后天需签到 | 距下次签到 = 2天 | 黄色 | 后天需签到 |
| 未签到 | 其他情况 | 红色 | 距下次签到N天 |

### 2.4 快速查询签到

- 按日期查看当天所有房间的签到情况
- 支持对任意房间在该日进行签到/撤销操作
- 日历选择器快速定位目标日期
- 显示该日签到率统计

### 2.5 批量操作

| 功能 | 描述 |
|------|------|
| 今日批量签到 | 对多选房间执行今日签到 |
| 今日批量撤销 | 对多选房间撤销今日签到 |
| 批量修改签到人 | 统一修改选中房间的签到人 |
| 批量设置历史签到 | 按日期范围批量设置历史签到状态 |

### 2.6 数据导出

| 导出类型 | 格式 | 内容 |
|----------|------|------|
| 房间状态表 | CSV | 房间名、签到人、最后签到日、下次签到日、距下次天数、状态 |
| 签到明细 | CSV | 房间名、签到人、签到日期、备注 |

### 2.7 数据存储

- **存储引擎**：浏览器IndexedDB
- **数据表**：
  - `rooms`：房间信息（id, name, signer, createdAt）
  - `checkins`：签到记录（id, roomId, checkInDate, createdAt）
- **数据导出/导入**：支持完整数据JSON备份与恢复

### 3.2 设计风格

- **配色方案**：
  - 主色：深蓝灰 `#1e293b`
  - 背景：`#f8fafc`
  - 状态色：绿色`#22c55e`、橙色`#f97316`、黄色`#eab308`、红色`#ef4444`
- **字体**：系统字体栈，标题14px，正文13px
- **交互**：悬停高亮、选中状态标记、按钮点击反馈
- **表格**：斑马纹、紧凑行高、分页或虚拟滚动

### 3.3 响应式设计

- 桌面优先设计，适配1024px以上屏幕
- 表格横向滚动适配窄屏
- 模态框居中显示，移动端全宽

## 4. 数据模型

### 4.1 房间表 (rooms)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | UUID主键 |
| name | string | 房间名称，唯一 |
| signer | string | 当前签到负责人 |
| createdAt | number | 创建时间戳 |

### 4.2 签到记录表 (checkins)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | UUID主键 |
| roomId | string | 关联房间ID |
| checkInDate | string | 签到日期 YYYY-MM-DD |
| createdAt | number | 创建时间戳 |

### 4.3 索引

- `checkins`: [roomId, checkInDate] 复合索引

## 5. 技术实现

- **架构**：单HTML文件，内联CSS和JavaScript
- **存储**：IndexedDB (Dexie.js封装)
- **UI**：原生HTML + CSS + JavaScript，无框架依赖
- **CSV处理**：PapaParse库
- **图标**：Unicode符号，无外部依赖
